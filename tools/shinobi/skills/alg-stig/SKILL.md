# Application Layer Gateway Security Requirements Guide

Use this skill when evaluating Infrastructure-as-Code (IaC) modules for compliance with the Application Layer Gateway (ALG) Security Requirements Guide (SRG).

## Instructions

1. Identify the applicable SRG requirements.
2. Inspect the provided implementation.
3. Determine which requirements can be evaluated deterministically.
4. Use available tools to inspect source code and configuration.
5. Report findings with the SRG rule identifier and supporting evidence.
